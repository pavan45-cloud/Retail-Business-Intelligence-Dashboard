# 📊 Retail Business Intelligence Dashboard

An interactive **Retail Business Intelligence Dashboard** built using **Python, Streamlit, Pandas, and Plotly** to analyze retail sales data and generate actionable business insights.

This project demonstrates data cleaning, exploratory data analysis (EDA), business intelligence reporting, and interactive dashboard development. It is designed as a portfolio project to showcase data analytics and visualization skills.

---

## 🚀 Features

* 📈 Interactive KPI Dashboard
* 💰 Total Sales, Total Profit & Profit Margin
* 📦 Orders & Customer Analysis
* 📊 Sales by Category
* 🌍 Profit by Region
* 📅 Monthly Sales Trend
* 🏆 Top 10 Most Profitable Products
* 📉 Top 10 Loss-Making Products
* 💹 Discount vs Profit Analysis
* 👥 Top Customers by Sales
* 🌎 Top States by Sales
* 📌 Business Insights & Business Recommendations
* 🎛️ Interactive Filters (Region & Category)

## ▶️ Getting Started

### Clone the repository

```bash
git clone https://github.com/pavan45-cloud/Retail-Business-Intelligence-Dashboard.git
```

### Navigate to the project folder

```bash
cd Retail-Business-Intelligence-Dashboard
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python -m streamlit run app.py
```
